Traiter une demande RGPD

Pour quelqu’un qui n’a plus accès à son compte et appelle pour exercer ses droits.

1 · Quelle demande ?

2 · Vérifier que c’est bien lui
Un code part sur le —, le numéro du compte. Demandez-lui de vous le lire.
3 · Saisir le code dicté
Demande sélectionnée : effacement du compte.

Un appel ne prouve rien. Sans le code lu à voix haute, n’importe qui connaissant un nom et un numéro pourrait faire effacer le compte d’un autre. Les trois demandes passent par le même sas — y compris la rectification, moins grave, parce qu’une exception dans un contrôle finit toujours par s’élargir.
« Effacer » veut dire anonymiser. Les traces des usages de bons sont conservées (elles justifient chaque achat de bon à une marque) ; ce qui disparaît, ce sont les données personnelles — nom, e-mail, téléphone. L’effacement est réservé à la direction ; un opérateur peut consulter et déclencher un export, pas supprimer.
Cette consultation est tracée. L’ouverture d’une fiche écrit une ligne au journal d’audit, à votre nom. L’export part directement par e-mail à l’utilisateur — le fichier contient toutes ses données personnelles, il n’a rien à faire sur votre poste.
